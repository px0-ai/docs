# px[0] Docs

This directory contains the documentation site built for [px0](https://px0.ai) and hosted on [docs.px0.ai](https://docs.px0.ai).

## Running the Documentation

Run the following commands from the docs directory to set up and start the development server.

```bash
mint dev
```
